THE SYSTEM - install on your phone (about 5 minutes, free)

1. Create a free account at github.com (skip if you have one).
2. Top-right "+" -> New repository. Name it: the-system. Public. Create.
3. On the repo page: "Add file" -> "Upload files". Drag in ALL files from this zip
   (index.html, manifest.webmanifest, sw.js, the four icon PNGs). Commit changes.
4. Repo "Settings" -> left menu "Pages" -> Source: Deploy from a branch ->
   Branch: main, folder: / (root) -> Save. Wait 1-2 minutes.
5. Your app is at: https://YOUR-USERNAME.github.io/the-system/
6. On your phone, open that link in Chrome -> menu (three dots) -> "Install app"
   (or "Add to Home screen"). It installs with its own icon and works offline.

Moving your progress: in the old version, Learn -> Settings -> Export backup,
then in the new one, Import backup.

Updates: when Claude gives you a new version, upload the new index.html to the
same repo (replace the old one). Your progress stays on the phone.
