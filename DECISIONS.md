# DECISIONS.md — why things are the way they are

- 2026-10-03 — Build on the owner's old "Gamify" Notion system (five Skills, XP hierarchy) rather than copy the video app. Replace its polynomial level curve with geometric (×1.07/1.08) so late levels never become multi-year walls.
- 2026-10-03 — 66-day arc kept as an opening chapter ("Awakening"), not a cap; levelling is infinite.
- 2026-10-03 — Streaks per task, +1% XP per 10 days capped at +50%; milestones grant shield tokens.
- 2026-10-04 — Avatar is an original anime-style character (not Solo Leveling IP); 21 forms every 5 levels; card rarity frames by tier.
- 2026-10-05 — HP penalty switched from "missed Essential task" to "fewer than N quests cleared" (default 6). 0 HP = Weakened (XP ×0.5) until 300.
- 2026-10-05 — Push-up/plank/run targets scale with the relevant stat level (start low, cap at 200/180 s/10 km).
- 2026-10-05 — Distribution: Claude artifact failed as a phone app (login + no install). Moved to GitHub Pages PWA, then to an APK built by GitHub Actions because "a real app" was the requirement.
- 2026-10-05 — Permanent keystore committed to the repo after throwaway keys broke updates twice. Explicit `signingConfigs` in Gradle; `~/.android` copy approach did not work on runners.
- 2026-10-06 — Each build gets its own release tag (`build-N`) because reusing `latest` failed intermittently.
- 2026-10-06 — Steps come from Health Connect (Samsung Health syncs into it); Samsung's own SDK is partner-only.
- 2026-10-06 — Food: Open Food Facts search + barcode + manual; no AI calorie estimation (would need a paid key in the app). Healthy-eating quest auto-ticks under target; "Finish diary" and rollover credit added after a missed day.
- 2026-10-07 — Accounting track made IFRS-only at the owner's request; UK GAAP lessons replaced by IFRS 19/IAS 12 advanced/IAS 32+IFRS 7/IFRS 16 lessor+IAS 40/IFRS 1+IFRS 15 advanced/regulator challenges.
- 2026-10-08 — Workflow split into two steps and `${{ }}` removed after GitHub's 21,000-char expression limit broke the build.
- 2026-10-08 — Persistent quick-log notification rejected by the owner; replaced by Nova-mappable app shortcuts and Quick Settings tiles, with no notification at all.
- 2026-10-08 — All `confirm()`/`alert()` replaced by in-app dialogs: the artifact sandbox silently blocks native dialogs.
- 2026-10-08 — Memory practice (recall / Feynman / question storm / three-pass notes) chosen over more content; lessons unlock one per day per track.
- 2026-10-11 — Adopted the CONTEXT/AGENTS/DECISIONS/TICKETS working method so any future session or Claude Code starts from the repo, not the chat.
- 2026-10-12 — Evaluated the ui-ux-pro-max skill: its style generator (claymorphism, rounded fonts) rejected as wrong for the status-window aesthetic; its UX rulebook adopted as a checklist. Fixed touch targets to Android 48 dp, Android back button now closes overlays, numeric keypads on number inputs.
- 2026-10-13 — To-do list added to the Quests tab (one-off tasks with XP by difficulty, optional due date, half XP when late) instead of overloading daily quests. Morning mobility added as a dungeon-able workout.
- 2026-10-18 — HP healing broadened as daily quests grew: tiered end-of-day heal (+20 at threshold, +50 at 80%, +100 flawless), plus gates, emergencies, boss, goals, recovery actions and storable healing potions from reward boxes. In-day healing capped at 150 HP to keep stakes. Deep-clean main quest added with per-step XP.
- 2026-10-22 — Pass streak added: consecutive days at the quest threshold heal +10 × streak (max +50) per day, +100 on every 7th day, +1 shield every 30th; a failed day resets it, rest days don't. Rewards consistency over perfection.
- 2026-10-22 — Static app shortcuts removed: Nova showed them on its search card even with Shortcut Search off. Replaced by three exported activities (LogWater, LogTeeth, LogStairs) that Nova gestures target via Activities; they don't appear in search, long-press or the drawer. Note: the 'Write Android sources' step is now ~18.8k of the 21k limit — split again before adding more Java.
- 2026-10-22 — UI pass after rendering every tab at 412 px: HP block rebuilt (Weakened pill, mini-stats for pass streak/shields/potions/best streak), duplicate Day and skill cards removed, Edit buttons hidden behind an Edit list toggle, ticked quests sink, finite quests collapse to progress + next step, to-do options folded, workout cards compact with exercises on demand and a ⋯ menu, Today moved above workouts, weekly review first in Progress, system log shows 10. Quests tab ~30% shorter.
- 2026-10-22 — Removed running (daily Run quest, weekly/monthly run goals), Call family and both room-tidy weekly tasks (covered by the deep-clean quest). Badminton goals now 2/week (300 XP) and 8/month (1,100 XP). Every section on every tab is collapsible via its heading; a CSS bug that forced rows inside collapsible sections to display:block (breaking flex rows) fixed.
- 2026-10-23 — Daily briefing: first open each day shows a [SYSTEM] window with a quote (50 curated — Stoics, classical, proverbs, and original System lines — plus the user's own) and today's mission summary; Accept = +5 XP. Quote also shown atop the Player tab; ♡ saves to a Quote vault in Learn. Toggle in Settings.
- 2026-10-23 — Swipe between tabs, page-turn style: swipe left = next tab, swipe right = previous (initially built reversed; corrected same day, existing setting migrated). Reversible or off in Settings. Ignores swipes from the outer 28 px (Android back gesture), short/diagonal swipes, horizontally scrollable areas, inputs, and any open overlay.
- 2026-10-23 — Weekly/monthly tasks fully editable (name, period, target, XP, main + up to 3 secondary subcategories at 25%). Auto-tracked goals editable via overrides in S.goalOv (name, target, XP, subcategories), hideable and resettable. Custom subcategories (S.customSubs) can be added to any skill in Settings; removable only while unused. Edit by tapping a goal's name (✎), no per-row buttons.
- 2026-10-23 — Weakened replaced by HP tiers (owner's rule): full HP ×1, 50–99% ×0.8 (INJURED), below 50% ×0.5 (WEAKENED). Simple mode added (hides Food tab, boss, shadow army, Rise rating; swipe skips hidden tabs). In-app update check: workflow injects APP_BUILD=$GITHUB_RUN_NUMBER into the APK's index.html; app polls GitHub releases/latest at most every 6 h and shows a Download banner (direct .apk link) with Later.
- 2026-10-23 — Subcategory info popup: tapping a subcategory in Skill details shows its description (SUB_DESC for the 25 built-ins; editable for custom ones), level progress, lifetime and weekly XP, growth rate, and every quest/goal/tracker/exercise/action currently feeding it.
